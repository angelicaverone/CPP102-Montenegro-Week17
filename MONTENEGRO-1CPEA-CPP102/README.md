## Project Description
Project Description The Simulated Device Monitoring and Alert System is a Python program that monitors simulated device temperature readings. It classifies each reading as NORMAL, WARNING, or CRITICAL based on its temperature value. 

## Features
Add a new temperature reading using whole numbers from 0 to 100 only. Classify every reading as NORMAL, WARNING, or CRITICAL. Inspect temperature statuses using indicators such as [OK], [!], and [ALERT]. Generate a numerical summary, including the total, average, lowest, and highest temperatures.
